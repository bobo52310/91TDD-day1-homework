# 專案實作步驟說明

本文件詳細說明如何使用 TDD/BDD 方式實作「分頁取值」功能。

## 專案需求

實作一個分頁計算功能，能夠：
- 將資料依指定數量分組
- 計算每組指定欄位的總和
- 回傳以逗號分隔的結果字串

### 需求範例

有以下資料：

| id | cost | revenue | sellprice |
|----|------|---------|-----------|
| 1  | 1    | 11      | 21        |
| 2  | 2    | 12      | 22        |
| 3  | 3    | 13      | 23        |
| 4  | 4    | 14      | 24        |
| 5  | 5    | 15      | 25        |
| 6  | 6    | 16      | 26        |
| 7  | 7    | 17      | 27        |
| 8  | 8    | 18      | 28        |
| 9  | 9    | 19      | 29        |
| 10 | 10   | 20      | 30        |
| 11 | 11   | 21      | 31        |

**測試案例 1**：以 3 筆為一組，計算 cost 總和
- 第一組：1+2+3 = 6
- 第二組：4+5+6 = 15
- 第三組：7+8+9 = 24
- 第四組：10+11 = 21
- **結果**：`6,15,24,21`

**測試案例 2**：以 4 筆為一組，計算 revenue 總和
- 第一組：11+12+13+14 = 50
- 第二組：15+16+17+18 = 66
- 第三組：19+20+21 = 60
- **結果**：`50,66,60`

## 實作步驟

### 步驟 1：環境準備

#### 1.1 初始化 Composer 專案

```bash
composer init
```

#### 1.2 安裝相依套件

```bash
composer require --dev phpunit/phpunit:^4.8
composer require --dev behat/behat:^3.0
```

#### 1.3 設定 Composer autoload

編輯 `composer.json`：

```json
{
    "autoload": {
        "psr-4": {
            "Tdd91\\": "src/"
        }
    }
}
```

執行：

```bash
composer dump-autoload
```

```bash
mkdir -p src
mkdir -p features/bootstrap
mkdir -p features/pagination
```

### 步驟 3：撰寫 Feature 檔案（Red）

建立 `features/pagination/fetch_value_by_pagination.feature`：

```gherkin
Feature: 分頁取值
  In order to 依據條件分頁取值
  As a 使用者
  I want to 依照不同需求組合取得回傳值

  Background:
    Given 現有資料列表
      | id | cost | revenue | sellprice |
      | 1  | 1    | 11      | 21        |
      | 2  | 2    | 12      | 22        |
      | 3  | 3    | 13      | 23        |
      | 4  | 4    | 14      | 24        |
      | 5  | 5    | 15      | 25        |
      | 6  | 6    | 16      | 26        |
      | 7  | 7    | 17      | 27        |
      | 8  | 8    | 18      | 28        |
      | 9  | 9    | 19      | 29        |
      | 10 | 10   | 20      | 30        |
      | 11 | 11   | 21      | 31        |

  Scenario Outline: 以 N 筆一組，取 Column 總和
    When 以 <n> 筆資料為一組取 <column> 總和
    Then 得到結果 <result>

    Examples:
      | n | column  | result     |
      | 3 | cost    | 6,15,24,21 |
      | 4 | revenue | 50,66,60   |
```

**說明**：
- 使用 `Background` 定義共用的前置資料
- 使用 `Scenario Outline` 和 `Examples` 執行多組測試
- 使用 `TableNode` 傳遞表格資料

### 步驟 4：初始化 Behat

```bash
vendor/bin/behat --init
```

這會建立基本的 `FeatureContext.php`。

### 步驟 5：建立 Context 類別（Red）

建立 `features/bootstrap/PaginationContext.php`：

```php
<?php
use Behat\Behat\Context\Context;
use Behat\Gherkin\Node\TableNode;
use Tdd91\Cart;

class PaginationContext implements Context
{
    private $data_source;
    private $count;

    /**
     * @Given /^現有資料列表$/
     */
    public function 現有資料列表(TableNode $table)
    {
        $this->data_source = $table->getColumnsHash();
    }

    /**
     * @When /^以 (.*) 筆資料為一組取 (.*) 總和$/
     */
    public function 以N筆資料為一組取Column總和($n, $column)
    {
        $cart = new Cart($this->data_source);
        $cart->setN($n);
        $cart->setColumn($column);
        $this->count = $cart->getCount();
    }

    /**
     * @Then /^得到結果 (.*)$/
     */
    public function 得到結果($result)
    {
        PHPUnit_Framework_Assert::assertEquals($result, $this->count);
    }
}
```

**說明**：
- `TableNode::getColumnsHash()` 將表格轉為陣列
- 正規表達式 `(.*)` 捕捉參數
- 使用 PHPUnit 的 Assert 進行驗證

### 步驟 6：設定 behat.yml

建立 `behat.yml`：

```yaml
default:
    suites:
        pagination:
            paths:    [ %paths.base%/features/pagination/fetch_value_by_pagination.feature ]
            contexts: [ PaginationContext ]
```

### 步驟 7：執行測試（應該失敗 - Red）

```bash
vendor/bin/behat --suite=pagination
```

**預期結果**：測試失敗，因為 `Cart` 類別還不存在。

### 步驟 8：實作 Cart 類別（Green）

建立 `src/Cart.php`：

```php
<?php

namespace Tdd91;

class Cart
{
    public $data_source;
    private $n;
    private $column;

    public function __construct(Array $data_source)
    {
        $this->data_source = $data_source;
    }

    public function getCount()
    {
        // 使用 array_chunk 將陣列分組
        $group = array_chunk($this->data_source, $this->n);

        // 計算每組的總和
        foreach ($group as $item) {
            $ans = 0;
            foreach ($item as $it) {
                $ans = $ans + (int)$it[$this->column];
            }
            $result[] = $ans;
        }

        // 回傳以逗號分隔的字串
        return implode(',', $result);
    }

    public function setN($n)
    {
        $this->n = $n;
    }

    public function setColumn($column)
    {
        $this->column = $column;
    }
}
```

**實作說明**：
1. 使用 `array_chunk()` 將資料依 N 筆分組
2. 對每組資料累加指定欄位的值
3. 使用 `implode()` 將結果陣列轉為逗號分隔的字串

### 步驟 9：再次執行測試（應該通過 - Green）

```bash
vendor/bin/behat --suite=pagination
```

**預期結果**：所有測試通過（綠燈）。

### 步驟 10：重構（Refactor）

檢視程式碼，可能的重構方向：

#### 10.1 加入輸入驗證

```php
public function setN($n)
{
    if (!is_numeric($n) || $n <= 0) {
        throw new InvalidArgumentException('N 必須是正整數');
    }
    $this->n = (int)$n;
}

public function setColumn($column)
{
    if (empty($column)) {
        throw new InvalidArgumentException('欄位名稱不能為空');
    }
    $this->column = $column;
}
```

#### 10.2 改善命名

```php
public function getCount()
{
    $groups = array_chunk($this->data_source, $this->n);
    $sums = [];

    foreach ($groups as $group) {
        $sums[] = $this->calculateGroupSum($group);
    }

    return implode(',', $sums);
}

private function calculateGroupSum($group)
{
    $sum = 0;
    foreach ($group as $row) {
        $sum += (int)$row[$this->column];
    }
    return $sum;
}
```

#### 10.3 加入型別宣告（PHP 7+）

```php
public function __construct(array $data_source)
{
    $this->data_source = $data_source;
}

public function setN(int $n): void
{
    $this->n = $n;
}

public function setColumn(string $column): void
{
    $this->column = $column;
}

public function getCount(): string
{
    // ...
}
```

### 步驟 11：確認重構後測試仍通過

```bash
vendor/bin/behat --suite=pagination
```

**重要**：每次重構後都要執行測試，確保功能沒有被破壞。

## TDD 循環總結

在這個專案中，我們遵循了 TDD 的 Red-Green-Refactor 循環：

1. **Red（紅燈）**
   - 撰寫 Feature 檔案描述需求
   - 建立 Context 類別呼叫尚不存在的 Cart 類別
   - 執行測試，確認失敗

2. **Green（綠燈）**
   - 實作 Cart 類別，使用最簡單的方式讓測試通過
   - 執行測試，確認通過

3. **Refactor（重構）**
   - 改善程式碼品質（命名、結構、驗證）
   - 執行測試，確保重構沒有破壞功能

## 常見問題

### Q1: Behat 找不到 Context 類別

**解決方案**：確認 `behat.yml` 中的 `contexts` 設定正確。

### Q2: 找不到 Cart 類別

**解決方案**：執行 `composer dump-autoload` 重新產生 autoload 檔案。

### Q3: 測試通過但結果不正確

**解決方案**：檢查 Feature 中的 Examples 資料是否正確，以及 Context 中的斷言邏輯。

## 學習重點

1. **先寫測試，再寫實作**：這是 TDD 的核心
2. **使用自然語言描述需求**：Gherkin 讓測試成為活文件
3. **小步前進**：每次只實作一個測試案例
4. **頻繁執行測試**：確保每個步驟都是正確的
5. **重構要有測試保護**：有測試才敢大膽重構

## 延伸練習

1. **加入更多測試案例**
   - 測試 sellprice 欄位
   - 測試不同的分組數量

2. **處理邊界條件**
   - 空資料
   - N 大於資料筆數
   - 欄位不存在

3. **加入錯誤處理測試**
   - 使用 Scenario 測試例外情況
   - 驗證錯誤訊息

4. **整合 PHPUnit**
   - 為 Cart 類別撰寫單元測試
   - 比較 BDD 測試和單元測試的差異
